# Classroom Pick! 🎡

A standalone classroom student picker made with HTML, CSS and JavaScript.

## Features
- Animated spinning wheel
- Fair random student selection
- Quick Pick alternative
- Optional "Remove student after being picked"
- Pick history
- Reset picks
- Shuffle names
- Sound toggle
- Fullscreen mode
- Responsive for projector, laptop and tablet
- No internet, Python or database required

## How to use
1. Open `index.html` in Chrome, Edge or Firefox.
2. Replace the sample names with your class list.
3. Click **Load Names**.
4. Click **SPIN THE WHEEL**.
5. The selected student appears in a celebration screen.
6. Turn on "Remove student after being picked" for no-repeat participation.

## Classroom idea
Use the wheel for recitation, answering questions, group reporting, board work, reading, demonstrations, or choosing classroom helpers.
