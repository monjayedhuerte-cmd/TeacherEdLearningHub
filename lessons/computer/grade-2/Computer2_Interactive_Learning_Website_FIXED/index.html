Teacher Ed says:

An output device is hardware that sends information from the computer to the user.

🖥️

Monitor

Displays text, pictures, and videos. It is also called a screen.

🖨️

Printer

Produces a hard copy of information from the computer onto paper.

🔊

Speaker

Produces sound from the computer.

🎧

Headset

Used for listening and speaking; it has headphones and a microphone.

👨‍🏫
Teacher Ed says:

When you press the power button, the computer does several jobs before the desktop is ready.

1Power ONYou press the power button.
2BIOS / POSTBasic startup software and checks begin.
3Boot DeviceThe computer finds where to start.
4Operating SystemThe OS loads the working environment.
5DesktopThe computer is ready.
🔄 BootingThe process of starting a computer.
❄️ Cold BootStarting from a powered-off state.
🔁 Warm BootRestarting a computer that is already running.
🧩 BIOSBasic startup software that helps begin the startup process.
🔎 POSTA startup check of important hardware.
🪟 Operating SystemMain software that provides the working environment.
🚪 Login / LogoutEnter or leave a user session.
⏻ ShutdownSafely turns off the computer.
