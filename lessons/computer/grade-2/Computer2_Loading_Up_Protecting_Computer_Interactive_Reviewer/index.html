LESSON 1

📦 Loading Up Your Computer

Software must be obtained and installed carefully. An installer helps set up software. Executable files can start programs, and compressed files may need to be decompressed.

Trusted source → Download / media → Installer → Configure → Use safely
SAFETY

🧠 Smart Download Rule

Check the source before downloading. Suspicious websites, links, or attachments may contain malware.

LESSON 2

🛡️ Protecting Your Computer

Use antivirus protection, stay alert online, protect personal information, back up important files, and maintain the computer.

BACKUP

☁️ Keep a Copy

Backups may be stored on an external hard drive or an online backup service so important files can be recovered.

MAINTENANCE
