TEACHER FACILITATOR

Teacher's Explanation

What is software installation?

Teacher: Software installation is the process of preparing a program so that it can work on a computer. An installer places the necessary program files in the proper locations and may ask us to choose options before the program is ready.

Think of it like bringing a new tool into your classroom. Before you can use the tool, you need to unpack it, put its parts in the right place, and follow the instructions.

Teacher tip: Learners should never install unfamiliar software without permission. Download only from trusted sources and ask an adult/teacher when unsure.
02

EXPLORE THE CONCEPT

Important words

Installer

A program that prepares and installs another program on the computer.

Executable

A file that can be run as a program.

Malware

Software designed to disrupt, damage, or gain unauthorized access.

Antivirus

Software that helps prevent, detect, scan for, and remove harmful software.

Decompression

Expanding compressed files back into usable files.

Default

A preselected option used when the user does not choose another option.

TEACHER EXPLANATION

What is happening at each stage?

1

Get the program

Download from a trusted source or use a legitimate CD/DVD. Check the source before opening the file.

2

Open Setup

The installer or setup program starts. It prepares the computer for the application.

3

Choose options

The installer may ask for language, license agreement, installation type, or location.

4

Install files

The setup program copies and prepares the required files. A progress bar may appear.

5

Finish

When installation is complete, click Finish or Close. Some programs may ask for a restart.

6

Use the program

The new program may appear in the Start menu and may also create a shortcut.
