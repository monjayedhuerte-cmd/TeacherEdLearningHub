What is software?

Software is the programs and instructions that tell a computer what to do. A computer needs software to perform many tasks.

💡 Example: a program for typing words.
📝

1. Productivity Software

Helps people work more easily and quickly at home or in an office.

  • Word processor — type and edit text
  • Spreadsheet — work with numbers and data
  • Presentation software — make slides
🏢

2. Business and Specialty Software

Used in areas such as banking, education, health, manufacturing, and other industries.

  • Inventory system — keeps track of items for sale
  • Payroll system — keeps records of workers' pay
🎓

3. Instructional / E-learning Software

Helps people learn and practice. It can teach and entertain at the same time.

  • Encyclopedia
  • Dictionary
  • Interactive tutorial
  • Interactive exercises
🖥️

GUI: The Screen You Use

A graphical user interface (GUI) lets people use a program through things they can see, such as windows, buttons, and icons.

💡 A window is the work area of an application.
🎛️

Ribbons, Tabs, and Commands

A ribbon contains tools and commands. Tabs organize tools by name. Icons are small pictures that represent commands.

💡 Click a tool or icon to give a command.
Remember: Application software helps people do tasks. It needs an operating system to work.
