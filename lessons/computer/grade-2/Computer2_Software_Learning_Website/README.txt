TEACHER ED LEARNING HUB — COMPUTER 2 INTERACTIVE LESSON
Topic: Lesson 10 — Lots of Software, Lots of Tasks

HOW TO OPEN
1. Extract the ZIP file.
2. Open the Computer2_Software_Learning_Website folder.
3. Double-click index.html. A modern browser is recommended.
4. Internet is not required; the site uses local HTML, CSS, JavaScript, and the supplied logo.

CONTENTS
- index.html: lesson pages and interactive sections
- style.css: responsive visual design
- script.js: answer checking, practice, games, scores, progress, rewards, and local storage
- assets/teacher-ed-logo.jpg: supplied logo used in the header, footer, and browser tab

LESSON CONTENT BASE
The lesson is based on the uploaded Computer 2 textbook photographs covering Lesson 10, “Lots of Software, Lots of Tasks”: software, application software, productivity software, business and specialty software, instructional/e-learning software, word processors, spreadsheets, presentation software, inventory and payroll systems, encyclopedias, dictionaries, interactive tutorials/exercises, GUI, ribbons, tabs, icons, commands, and shutting down the computer. The uploaded pages introduce shutting down but do not provide a full illustrated step sequence, so this website does not invent detailed shutdown steps.

FEATURES
- Connect, explicit teaching, teacher model, guided practice, independent practice, games, spiral review, final mastery check, remediation, and reflection
- Quick Pick, Sort It, and Memory Match games
- Hints, corrective feedback, stars, badges, progress tracking, retry, and missed-question review
- Responsive layout for phones, tablets, and computers
- Progress is stored locally in the browser; use Reset progress to clear it

No database or account is required. Progress is stored only in the current browser/device.
