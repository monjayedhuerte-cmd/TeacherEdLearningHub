# Teacher Ed Learning Hub — Interactive Lesson
## Lesson 8: Connected, Small & Wide (Types of Computer Networks)

### Files
- `index.html` — complete responsive interactive lesson
- `assets/teacher-ed-logo.png` — the supplied Teacher Ed logo

### Run locally
1. Extract the ZIP file.
2. Keep the `assets` folder beside `index.html`.
3. Double-click `index.html` to open it in a modern browser.

### Features
- EDJAY navy/gold branding using the provided logo
- Horizontal lesson tabs positioned at the top, with a progress indicator
- Full-screen lesson view toggle (uses browser Fullscreen API where supported)
- Engage question, concept cards, network scope scenarios, flashcards
- Practice quiz with feedback and retry
- Knowledge check with score and review advice
- School network design prompt and sample response
- Matching mastery challenge and reflection
- Responsive layout and reduced-motion support

### Notes
- This is a front-end-only lesson. Student responses are not sent to a server or synchronized across devices.
- The lesson content is based on the supplied lesson pages. TAN is retained as named in the supplied reference; it is not as universally standardized a category as LAN, MAN, and WAN.
- Browser testing should be completed on the target devices before classroom deployment.
