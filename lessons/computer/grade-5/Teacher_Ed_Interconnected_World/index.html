🧠 STAGE 4 · LEARN

Understand the parts of an interconnected world

Read the short explanations, study the diagrams, and check each important term.

Explicit instruction

1. The Internet

The Internet is a vast network of computers and networks around the world. It allows devices and networks to communicate and exchange information.

The reference describes ARPANET as an early major computer network launched in 1969 and notes that the Philippines connected to the Internet on March 29, 1994.

2. The World Wide Web (WWW)

The Web is a system for sharing information through the Internet infrastructure. Web pages may contain hyperlinks, which take users to another page, file, or resource when selected.

Tim Berners-Lee invented the World Wide Web in 1989, according to the supplied reference.

3. Internet infrastructure

A modem helps connect a device or local network to an Internet service. An Internet Service Provider (ISP) provides Internet access. The reference also introduces Points of Presence (POPs) and Network Access Points (NAPs).

4. IP address and DNS

An IP address identifies a device or network interface for Internet communication. The Domain Name System (DNS) helps translate a domain name into an IP address so a browser can find the appropriate destination.

Analogy: A domain name is like a contact name; an IP address is like a number used by the network to reach the destination.

5. Web browser, URL, and HTTP

A web browser is an application used to access web pages. A URL is the address of a web resource. HTTP specifies how web content is requested and transferred; HTTPS adds transport security.

6. Protocols

TCP/IP
A protocol suite that enables network communication and data delivery.
HTTP
Used to transfer web resources.
SMTP
Used to send email.
FTP
A protocol designed for file transfer.
