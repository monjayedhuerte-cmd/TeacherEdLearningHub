## Learning design
The lesson follows the Teacher Ed master workflow:
Engage → Connect → Explore → Learn → Guided Practice → Practice → Think → Review → Check → Master → Reflect → Celebrate.

## Files
- `index.html` — complete standalone website (HTML, CSS, JavaScript)
- `assets/` — supplied textbook pages and the generated explanatory infographic

## Run locally
1. Extract the ZIP file.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a current version of Chrome, Edge, Firefox, or Safari.
4. Use the top tabs to move between stages. Use **Full screen** for classroom presentation.
5. Use **Focus view** to reduce distractions and **A+ Readable text** to enlarge text.

## Privacy and storage
The lesson has no backend, analytics, advertising, or network calls. Activities run locally in the browser. Reflection answers are not transmitted or saved to a server. Assessment results exist only in the current page session.
