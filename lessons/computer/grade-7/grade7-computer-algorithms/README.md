# Grade 7 Computer — Algorithms Interactive Lesson

**EDJAY — Teach. Lead. Inspire.**

This static website was created from the uploaded Grade 7 Computer lesson photos and the provided Grade 7 master prompt.

## Topic
How Algorithms Work and Algorithm Analysis

## Files
- `index.html` — main learning website
- `lesson.html` — duplicate entry page
- `style.css` — responsive design
- `script.js` — interactions, activities, quiz, scoring, mastery
- `data/lesson.json` — lesson content/data
- `assets/logo.png` — uploaded Teacher Ed logo
- `assets/favicon.png` — uploaded logo used as browser tab icon
- `assets/images/` — uploaded source lesson photos

## Running
Because the lesson data is loaded with `fetch()`, use a static local server such as VS Code Live Server rather than opening `index.html` directly with `file://`.

## Branding
The uploaded logo is used in the header, footer, and favicon.

## Source note
Content is based on the provided lesson materials. The site simplifies wording for Grade 7 learners while retaining the source's concepts and terminology.
