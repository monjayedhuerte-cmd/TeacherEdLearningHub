# Grade 7 Algorithms — Interactive Lesson
Created for Teacher Ed.

## Coverage
Chapter 2: Algorithms / Lesson 1: Algorithm Definition

The lesson is based on the supplied textbook pages and expands them into a student-friendly interactive Grade 7 learning experience. It covers:
- Definition of algorithm
- Input → Algorithm → Output
- Origin and historical context
- Importance and real-world uses
- Sequencing, selection, iteration
- Algorithm vs. pseudocode vs. program
- Linear search and pseudocode
- Characteristics/properties: input, output, clarity, feasibility, language independence, finiteness, effectiveness, deterministic behavior
- Practice activities and a 20-item assessment
- Exit ticket
- Local progress saving and dark mode

## How to use
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. No server or installation is required.
4. Student progress is saved in the browser's localStorage.

## Teacher note
The lesson intentionally paraphrases and expands the supplied textbook content rather than reproducing the textbook pages verbatim.
