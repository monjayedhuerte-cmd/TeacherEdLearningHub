⚙️ Core Strategies

Brute Force: try possibilities.

Recursive: solve smaller versions of the same problem.

Divide & Conquer: divide, conquer, combine.

Dynamic Programming: reuse stored results.

🧠 More Strategies

Greedy: choose the best local option.

Randomized: use random choices.

Backtracking: explore and undo choices that fail.

📊 Algorithm Analysis

Best case: minimum time.

Worst case: maximum/long time.

Average case: considers typical/random inputs.

⏱️ A Priori vs Posterior

A priori: theoretical, before implementation.

Posterior: empirical, after implementation using observed statistics such as time and space.
