🔢 The Number Pad

A separate set of number keys usually found on the far right of a standard keyboard.

What is a number pad?

The lesson describes the numeric keypad, number pad, numpad, or ten keys as a palm-sized, usually 17-key section of a standard computer keyboard, usually on the far right.

  • It contains number keys 0 through 9.
  • It includes a decimal point.
  • It makes entering large amounts of numerical data easier.
  • The keys can also serve as cursor-control keys.
For the number pad to enter numbers, make sure the Num Lock light is on. If it is not on, press the Num Lock key. When Num Lock is on, number keys enter numbers where the cursor is.
