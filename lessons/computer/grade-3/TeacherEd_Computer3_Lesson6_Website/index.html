PHASE 2 — TEACH

Learn in small chunks

🧩

System Software

System software consists of programs that let you manage, maintain, and control the computer.

System software = Operating system + Utility programs
🖥️

Operating System (OS)

The OS manages computer hardware and software resources and provides common services for computer programs.

🛠️

Utility Programs

Utility programs help keep the computer working properly. They can rearrange and clean files and help fix problems.

⚡

Multitasking & Throughput

Multitasking means performing two or more tasks at the same time. Throughput is the amount of work a computer can do at a certain time.

🧠 Important OS jobs

📥 Receives and understands commands.
⏱️ Helps commands get performed without unnecessary delay.
🧠 Makes sure needed resources are available.
💾 Helps the processor, storage, software, and external devices get needed data and instructions.
🗂️ Keeps track of files stored on the computer.
🔐 Helps keep files safe from unauthorized users.
🚨 Alerts you about possible system problems or system failure.
