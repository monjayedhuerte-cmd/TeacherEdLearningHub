TEACHER ED LEARNING HUB — EPP GRADE 4
Linis Quest: Mga Paraan ng Paglilinis ng Bahay at Bakuran

FILES
- index.html — website structure and branding
- style.css — responsive design
- script.js — question logic, progress, scoring, hints, confidence checks, sorting, results
- data.js — structured question bank
- assets/teacher-ed-logo.png — Teacher Ed logo used in header, sidebar, footer
- assets/favicon.png — browser-tab icon

HOW TO RUN
1. Extract the ZIP, preserving the folder structure.
2. Open index.html in a modern browser.
3. Core functionality works without a backend. Google Fonts are optional and have system-font fallbacks.
4. To publish online, upload the entire folder to GitHub Pages or another static host.

LESSON SCOPE
Built from the supplied EPP Grade 4 textbook photos, pages 39–41. Topics include cleaning ceilings, walls, windows, floors, furniture and fixtures; yard maintenance; separating recyclable/non-biodegradable items; composting suitable organic material; keeping drains clean; and safety practices while cleaning.

SOURCE ACCURACY NOTE
Question wording and reviewer explanations are based on the supplied textbook photos. Some tool-use and electrical-safety instructions should be carried out only with adult supervision. The site adds a general precaution not to mix cleaning products; that is a safety addition, not a quoted textbook instruction.

PROGRESS AND PRIVACY
Progress is stored in localStorage on the current browser/device. No student name is collected and no results are sent to a server. Use Restart reviewer to clear the saved progress.

TEACHER REVIEW
Please preview before classroom use. The reviewer is a practice aid and does not replace teacher instruction or the textbook.
