CLASSROOM ATTENTION GETTER — TEACHER ED

Open index.html in Chrome, Edge, or Firefox.

FEATURES
- Eyes on Me call-and-response
- Class, Class / Yes, Teacher
- Brain Ready / Learning Ready
- Silent Signal
- Clap Pattern
- 5-second Countdown
- Magic Word
- Custom attention message
- Visual animations
- Sound effects with on/off control
- Fullscreen mode for classroom projectors
- Stop and Replay controls
- Works offline; no server/database required

Keep index.html, style.css, and script.js in the same folder.
