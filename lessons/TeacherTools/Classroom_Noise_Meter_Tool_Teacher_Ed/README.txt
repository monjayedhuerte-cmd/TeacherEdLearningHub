CLASSROOM NOISE METER — TEACHER ED

Open index.html in Chrome, Edge, or Firefox.

HOW IT WORKS
1. Click START METER.
2. Allow microphone access.
3. The browser analyzes microphone volume locally.
4. The meter displays a relative 0–100 classroom noise index.
5. Choose a target for Silent, Whisper, Talk, or Present.

IMPORTANT
This is a classroom noise indicator, NOT a calibrated decibel meter. Different microphones, laptops, speakers, room acoustics, and browser settings produce different readings. Use the number as a visual classroom guide, not as an exact dB measurement.

FEATURES
- Live microphone noise visualization
- Large projector-friendly gauge
- Quiet / Whisper / Moderate / Loud / Too Loud states
- Visual warning animation when too loud
- Optional alert sound
- Classroom target levels
- Fullscreen mode
- Privacy-friendly: audio is processed locally and is not recorded or saved
- Works without a server after opening the page

If microphone access does not work from a local file in a particular browser, run the folder from a local development server (for example VS Code Live Server). No cloud server is required.
