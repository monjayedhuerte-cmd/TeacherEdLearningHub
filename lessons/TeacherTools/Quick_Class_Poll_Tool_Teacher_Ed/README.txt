QUICK CLASS POLL — TEACHER ED

Open index.html in Chrome, Edge, or Firefox.

FEATURES
- Create a custom poll question
- 2–6 choices
- Preset classroom polls
- Student vote mode
- Live vote counts
- Results bars and percentages
- Leading-answer indicator
- Reset poll
- 30 sec / 1 min / 2 min timer
- Optional sound
- Fullscreen/projector mode
- CSV export
- Offline; no server/database required

HOW TO USE
1. Create a question or choose a preset.
2. Project the poll.
3. Students tap their choice on the device they are using.
4. Click SHOW RESULTS when ready.
5. Review the class pattern and adjust your discussion.

NOTE
This version is a lightweight local classroom poll. Votes are stored only in the current browser session and are not synchronized between different student devices. For true multi-device live voting, a backend such as Firebase would be needed.
