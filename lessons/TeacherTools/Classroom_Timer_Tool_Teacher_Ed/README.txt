CLASSROOM TIMER — TEACHER ED

Open index.html in Chrome, Edge, or Firefox.

FEATURES
- 30-second, 1, 2, 5, 10, and 15-minute presets
- Custom minutes and seconds
- Start / Pause / Reset
- Circular visual countdown
- 10-second warning
- End alarm
- Sound toggle
- Fullscreen mode
- Classroom purpose presets:
  Think Time, Pair Discussion, Group Work, Quiz Time, Brain Break, Exit Ticket
- Responsive projector/tablet layout
- Works offline with no server or database

The files are standalone. Keep index.html, style.css, and script.js in the same folder.
