STUDENT PARTICIPATION HUB
Teacher Ed

FILES
- index.html
- style.css
- script.js

HOW TO USE
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Replace the sample student names with your class list.
4. Click Load Class.
5. Choose Wheel, Mystery Cards, or Quick Pick.

IMPORTANT
- The tool works offline.
- No server or database is required.
- Names are kept only in the current browser page.
- "Remove picked student" is ON by default for fairer participation.

PARTICIPATION MODES
1. Wheel: animated spinning wheel.
2. Mystery Cards: classroom-friendly reveal.
3. Quick Pick: instant random selection.

RESET
Use Reset in Pick History to put all picked students back into the active list.
