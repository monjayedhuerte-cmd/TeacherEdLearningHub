AP 3 – Ang Kasaysayan ng Ating Pamayanan
Interactive classroom website for Teacher Ed.

FILES
- index.html — main website; double-click to open in Chrome/Edge.
- assets/ — selected visual references cropped from the uploaded textbook photos.

FEATURES
- Child-friendly History Explorer design
- Lesson flow: Tuklasin, Ihambing, Alamin, Subukin
- Visual discussion gallery
- Timeline activity
- 3 interactive games
- Score and badge feedback
- Teacher Mode random student picker
- Student names are stored only in this browser via localStorage

OFFLINE
The website works offline. No external libraries are required.

NOTE
The lesson content is based on the pages supplied by the teacher. The textbook images are used here as visual references for the classroom material.
