TEACHER ED LEARNING HUB – AP3 KASAYSAYAN AT KULTURA QUEST

Files:
- index.html
- style.css
- script.js
- BrandLogo.png

How to use:
1. Keep all four files in the same folder.
2. Open index.html in a modern browser.
3. The website works offline; no framework or database is required.
4. Progress, stars, badges, best scores and practice data are saved in browser localStorage.
5. Use Reset Progress from the Progress page to clear saved data.

Lesson coverage:
- Kasaysayan ng Ating Pamayanan
- Pagkilala sa Kultura / Kulturang Pilipino

Built with HTML5, CSS3 and Vanilla JavaScript.
The supplied Teacher Ed Learning Hub logo is used for the header, footer and browser favicon.
