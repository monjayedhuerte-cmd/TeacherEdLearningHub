TEACHER ED LEARNING HUB — AP3 CULTURE QUEST

Contents:
- index.html: interactive reviewer
- style.css: responsive layout and print styling
- script.js: 30-question interactive reviewer, immediate feedback, progress, answer review
- assets/: Teacher Ed logo and textbook reference pages for Aralin 9 and Aralin 10

How to use:
1. Extract the ZIP file.
2. Open index.html in an up-to-date browser (Chrome, Edge, Firefox).
3. Internet is not required for the local reviewer and included reference images.
4. Use the Memory Booster before the 30-item mastery check.

Note:
Questions use the lesson pointers and textbook pages included in this package. For specific details not stated in the referenced pages, learners are directed back to the lesson rather than being given unsupported claims.
