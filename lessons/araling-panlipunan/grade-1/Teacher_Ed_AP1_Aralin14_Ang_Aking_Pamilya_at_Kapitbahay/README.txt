# Teacher Ed Learning Hub — Aralin 14

**Araling Panlipunan • Baitang 1**
**Ang Aking Pamilya at ang Aming mga Kapitbahay**

## Files
- `index.html` — main interactive lesson
- `style.css` — responsive UI
- `script.js` — interactions, games, quizzes, localStorage
- `assets/` — supplied Teacher Ed Learning Hub logo and lesson-page images

## Run
Open `index.html` in a browser. No framework or database is required.

## Included
- 11-phase instructional flow from the supplied master prompt
- Filipino-first Grade 1 language
- Teacher Ed Learning Hub branding and favicon
- Connect, Teach, Model, Guided Practice, Independent Practice
- Game Zone: Mabuti o Hindi? + Bansang Kapitbahay
- Spiral Review, Application, Mastery Check
- Remediation / enrichment
- Stars, badges, best score, progress saving
- Reset progress
- Mobile/touch-friendly layout
- Source Corner using the supplied lesson images
