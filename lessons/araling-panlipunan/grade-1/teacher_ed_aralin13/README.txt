TEACHER ED LEARNING HUB — ARALIN 13
Ang Aking Pamilya ay Nagmamahalan

GRADE 1 • ARALING PANLIPUNAN

Nilalaman: Batay sa mga larawang ipinadala para sa Aralin 13, lalo na sa mga halimbawa ng pagmamahal, paggalang, pagtutulungan, pakikinig, pagbabahagi, pag-aalaga, at pagsasama-sama ng pamilya.

FILES
- index.html — main website
- styles.css — responsive UI
- app.js — interactions, games, quiz, progress, teacher report
- assets/logo/teacher-ed-logo.jpg — provided Teacher Ed logo
- assets/images/ — cropped lesson photos from the uploaded pages

RUN
1. I-extract ang ZIP.
2. Buksan ang index.html sa Chrome/Edge/Firefox.
3. Walang internet connection o server ang kailangan.

TEACHER USE
- I-project ang website sa classroom.
- Gamitin ang Attention button sa footer para sa “Eyes here in 3…2…1…”.
- Tawagin ang mga mag-aaral sa Connect, Think, Challenge, at Reflection sections.
- Ang Teacher Report ay nagbibigay ng simpleng evidence summary mula sa mga interaction na nasagutan sa session.

NOTE
Ang mga lesson photo ay maingat na ni-crop mula sa mga larawang ipinadala. Ang website ay instructional tool; guro pa rin ang facilitator.
