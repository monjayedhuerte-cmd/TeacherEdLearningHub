ARALING PANLIPUNAN 1 — ANG LAKI NG AKING PAMILYA
Interactive Classroom Website

FILES
- index.html
- style.css
- script.js
- assets/ (6 supplied family images)

HOW TO USE
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. No internet connection is required.
4. For projector/classroom presentation, click ⛶ for fullscreen.
5. Teacher notes can be toggled with 📝 or keyboard N.
6. Use ← and → to move through the lesson.
