AP 1 — ANG LAKI NG AKING PAMILYA
Glassmorphism Interactive Classroom Website

HOW TO USE
1. Open index.html in Chrome, Edge, or another modern browser.
2. For classroom projection, click the ⛶ button for Full Screen.
3. Use the top navigation or Left/Right arrow keys to move through the lesson.
4. The lesson flow follows the Daily Lesson Log:
   Motivation → Observation → Discussion → Interactive Activity → Needs → Application → Generalization → Assessment.
