TEACHER ED LEARNING HUB
Araling Panlipunan 4 — Ekonomiya Quest
Topic: Aralin 7, Mga Hamong Hinaharap ng mga Gawaing Pangkabuhayan sa Pilipinas

FILES
- index.html: reviewer structure
- styles.css: responsive visual design
- script.js: interactions, quizzes, feedback, local progress
- assets/teacher-ed-logo.png: supplied Teacher Ed logo/favicon

HOW TO USE
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. Internet is not required for the core reviewer. The optional Google Fonts import falls back to system fonts if offline.
4. To publish on GitHub Pages, upload all files while preserving the assets folder.

NOTES
- Progress and best quiz score are saved in localStorage on the same browser/device.
- The reviewer content is based on the supplied textbook photos (pages 207, 209–215) and the stated Araling Panlipunan 4 learning goals.
- Textbook historical figures and policy details should be checked against the teacher's current module before formal testing.
