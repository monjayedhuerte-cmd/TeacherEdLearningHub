TEACHER ED LEARNING HUB — ENGLISH GRADE 4 INTERACTIVE REVIEWER
Lesson focus: “Mickey and the Troll” (textbook pages supplied by the user), vocabulary, forms and conventions of film/moving pictures (lighting), and the three cases of pronouns.

FILES
- index.html: main responsive reviewer page
- style.css: layout, responsive styling, keyboard focus and feedback states
- app.js: all questions, interactive activities, scoring, timer, feedback, and progress
- assets/teacher-ed-logo.png: Teacher Ed logo used in header, footer, welcome card, results, favicon and touch icon

INCLUDED LEARNING FLOW
Welcome → Recall → Memory Booster → Remember It → Quick Fire → Sort/Match → Fix Mistake → Story-specific Honesty Game → Boss Challenge → Mini Mock Quiz → Results/weak-area review → 5 Things to Remember → 30-Second Review → Confidence check.

FEATURES
- Mobile-first responsive layout and large touch targets
- All visible quiz cards have actual questions and selectable answers
- Instant right/wrong feedback with explanations
- Hints, XP, accuracy, answered-item tracking, and local browser progress
- Match activity with 10 pairs
- Restart controls, 30-second timer, confidence check, and missed-topic review
- Runs offline; no external libraries or internet connection required

HOW TO USE
1. Extract the ZIP while preserving the assets folder.
2. Open index.html in a modern browser.
3. For progress saving, keep browser storage enabled.
4. If deploying to a website, upload all files and the assets folder together.

SOURCE NOTE
The story content is summarized rather than reproduced in full. Vocabulary and concepts follow the provided photos. Lighting descriptions such as daylight and artificial-light colour casts are presented as described on the photographed textbook page.
