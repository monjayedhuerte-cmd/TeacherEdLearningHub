# Grade 6 English Interactive Learning Website

Open `index.html` in a browser.

## Included/fixed
- Working navigation and progress bar
- Complete lesson content from the supplied pages
- Working multiple-choice activities with fixed answer keys
- Open-ended inputs with `SHOW SAMPLE` buttons
- Guided feedback and retry behavior
- 6-question practice game
- 10-item assessment with scoring and explanations
- Final Boss input fields and sample answers
- Results/mastery dashboard
- Responsive mobile/tablet/desktop layout
- Supplied Teacher Ed logo and textbook page references

No external libraries are required.
