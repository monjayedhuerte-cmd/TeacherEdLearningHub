# Teacher Ed — Dust Under the Rug

Grade 6 English interactive learning website based on the supplied textbook pages.

## Files
- index.html
- style.css
- script.js
- assets/teacher-ed-logo.jpg

## Run
Open `index.html` in a modern browser. No server or build step is required.

## Learning sequence
Engage → Connect → Explore → Read → I Do → We Do → You Do → Practice → Apply → Think Deeper → Review → Check → Master → Reflect → Celebrate

The site includes responsive navigation, reading controls, speech synthesis where supported, guided feedback, vocabulary practice, an educational game, open-response sample answers, a 15-item assessment, and a final application challenge.
