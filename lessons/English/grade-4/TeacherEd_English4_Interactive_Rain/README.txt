TEACHER ED LEARNING HUB — ENGLISH QUEST (GRADE 4)

FILES
- index.html: reviewer structure and page content
- style.css: responsive layout and visual styling
- script.js: interactions, feedback, scoring, matching game, mini-checks, and saved progress
- data.js: editable question bank and matching vocabulary
- assets/teacher-ed-logo.png: logo used in the header, footer, hero, and browser tab

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. No server or installation is required. The reviewer runs locally.
4. Progress is saved in the browser on the device using localStorage.
5. To edit questions, update data.js. Keep the question object fields q, o, a, why, h (quick quiz) and q, o, a, why, topic (mastery quiz).
6. For offline use without an internet connection, the page still works; the optional Google font may fall back to system fonts.

CONTENT COVERAGE
- Waiting for the Rain: Velu, Amma, drought, land-rest theme, story-based inference
- Vocabulary: crimson, barren, dejected, ploughed, puzzled
- Cause and effect and signal words
- Eight mini-check questions (one per main skill/topic)
- Action verbs and linking verbs
- Pronouns and antecedents
- Inference
- Non-verbal cues and pagmamano from the other supplied pages

SOURCE LIMIT
Content follows the supplied textbook photos. The reviewer summarizes the visible excerpt of Waiting for the Rain and does not claim to reproduce the complete story.
