# Teacher Ed Learning Hub — Filipino 3 Part 2: Pang-angkop

Complete interactive lesson based on the supplied textbook photographs (pages 132–133).

## Source-based content
- Pang-angkop connects the panuring and salitang tinuturingan.
- **na**: used when the preceding word ends in a consonant.
- **-ng**: used when the preceding word ends in a vowel or /n/.
- Examples are based on the supplied textbook pages, including masipag na bata, mabait na guro, matamis na mangga, masayang pag-aaral, magandang umaga, pusong bato, halamang malago, and bayang magiliw.
- Page 133 items are converted into interactive practice.

Connect → Explain → Model → Guided Practice → Meaningful Game → Application → Mastery
