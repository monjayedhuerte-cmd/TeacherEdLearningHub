# Science 1 — Taking Care of the Nose

Interactive primary lesson based on the supplied **Science Wonders 2** photographs (pages 68–69) and the user's Primary Interactive Learning master prompt.

## Included
- ENGAGE → CONNECT → EXPLORE → LEARN → GUIDED PRACTICE → PRACTICE → THINK → REVIEW → CHECK → MASTER → REFLECT → CELEBRATE
- Cropped lesson illustrations from the supplied photographs
- 10-question, 3-choice check quiz
- Guided practice and matching-style practice
- Flip-card review
- Teacher Mode
- Local progress saving
- Responsive design for desktop, tablet, and mobile
- Teacher Ed Learning Hub branding

## Source-based content
The lesson focuses on the photographed material:
- Use clean, soft tissue/cotton/handkerchief when cleaning the nose.
- When traveling, cover the nose with a clean tissue/handkerchief or wear a nose mask to help avoid polluted air.
- Do not put small objects inside the nose.
- Do not blow the nose hard.
- See a doctor at once if the child can hardly breathe through the nose.
