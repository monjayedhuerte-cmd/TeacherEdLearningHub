# Sense Organ Detectives — Grade 1 Science

Interactive hands-on follow-up activity for **Sense Organs Working Together**.

## Features
- 5 detective stations: Mystery Food, Read & Listen, Touch Detective, Sound Detective, Safety Mission
- Choice-based interactive missions with instant feedback
- Score, stars, progress, badge, replay, and localStorage
- Student mission card and print button
- Teacher Ed Learning Hub logo in header, footer, and favicon
- Responsive, offline, vanilla HTML/CSS/JavaScript
- No external libraries or internet connection required

## Classroom use
Use the website to introduce each station, then perform the safe hands-on version in class. Do not let pupils taste unknown foods or touch hot, sharp, dirty, or otherwise unsafe objects.

Open `index.html` in Chrome, Edge, or Firefox.
