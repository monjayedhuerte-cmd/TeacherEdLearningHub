# Science 1 — Taking Care of the Eyes

A standalone interactive Grade 1 Science lesson built from the user's supplied lesson photos and the Primary Interactive Learning Website Master Prompt.

## Included
- 12-stage learning flow: Engage → Connect → Explore → Learn → Guided Practice → Practice → Think → Review → Check → Master → Reflect → Celebrate
- Cropped lesson visuals from the supplied textbook photos
- Teacher Ed branding/logo
- Safe/unsafe eye-care games
- 8-question practice
- 10-question check
- 5-question mastery challenge
- Flashcard review
- Score, progress, badges, restart, and celebration animation
- Responsive design for phone, tablet, and desktop
- No external libraries required

## How to use
Open `index.html` in a modern browser. Keep the `assets` folder beside it.
