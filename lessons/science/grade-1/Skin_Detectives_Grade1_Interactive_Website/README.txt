# Skin Detectives – Grade 1 Science Interactive Website

A classroom-ready, HTML/CSS/JavaScript interactive lesson for:
"The Skin and the Sense of Touch and Feeling"

## Files
- index.html – lesson and interactive content
- style.css – responsive design and animations
- script.js – games, quiz, skin-part interaction

## How to run
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Double-click index.html, or use the Live Server extension.
4. The site works offline; no internet connection is required.

## Included
- Attention-grabbing Mystery Touch Box motivation
- Hot/cold, soft/hard, smooth/rough, pressure and pain concepts
- Interactive skin diagram with clickable parts
- Epidermis, dermis, hair, pores, sweat gland, nerve endings and oil ducts
- Touch classification game
- Quiz with scoring
- Exit ticket
- Teacher quick guide
- Mobile-responsive design
