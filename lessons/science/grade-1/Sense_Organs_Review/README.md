# Science 1 — Sense Organs Review

Teacher Ed Learning Hub interactive reviewer based on the Science Wonders 2 pages supplied by the teacher.

## Topics
- Sense organs working together
- Proper care of the eyes
- Proper care of the ears
- Proper care of the nose
- Proper care of the skin
- Proper care of the tongue, teeth, and mouth

## Features
- Retrieval practice
- Memory Booster
- Quick Fire
- Match & Connect
- Fix the Mistake
- Sense Safety Quest
- Boss Challenge
- Visual source gallery using cropped teacher-provided book photos
- Immediate feedback and hints
- Weak-area suggestion
- LocalStorage progress
- Mobile-friendly layout
- Teacher Ed Learning Hub branding

## Run
Open `index.html` in a browser. No backend or framework is required.
