# Sense Explorers — Grade 1 Science

A browser-based interactive Science Quiz Adventure for Teacher Ed Learning Hub.

## Topic
The Five Sense Organs:
- Eyes — Sight
- Ears — Hearing
- Nose — Smell
- Tongue — Taste
- Skin — Touch

## Files
- index.html — main website
- style.css — visual design
- script.js — quiz/game logic
- assets/teacher-ed-logo.png — provided Teacher Ed logo

## How to use
1. Keep the folder structure intact.
2. Open `index.html` in a modern browser.
3. The site works without a backend.
4. Scores, badges, progress, and sound preference use browser localStorage.

## Easy editing
The question bank is near the top of `script.js` inside `const worlds`.
Each question follows:
[type, visual, question, correct answer, distractor 1, distractor 2, distractor 3, explanation, hint]

You can add more questions to each world without changing the game engine.
