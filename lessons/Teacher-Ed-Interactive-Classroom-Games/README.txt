Teacher Ed Interactive Classroom Games
======================================

A standalone HTML/CSS/JavaScript classroom motivation game website.

Included:
- 15 classroom games
- Responsive 5-column desktop game library that adapts to tablets/mobile
- Search, grade, subject, duration, and energy filters
- Guess the Picture with built-in pictures AND optional image upload
- Timers, sound effects, animations, scoreboard, random picker, saved setups
- Teacher Ed logo used in header, footer, and browser favicon
- No registration, backend, or database required

Files:
index.html
style.css
script.js
BrandLogo.png

Open index.html in Chrome, Edge, or another modern browser.
