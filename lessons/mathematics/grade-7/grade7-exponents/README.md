# Grade 7 Exponents — EDJAY Interactive Learning Website

A responsive, offline-friendly, single-page HTML/CSS/JavaScript lesson based on the supplied textbook pages 139–147.

## Included
- Concrete–Pictorial–Abstract (CPA) Singapore Mathematics-inspired flow
- Engage → Connect → Explore → Learn → Guided Practice → Practice → Think → Review → Check → Master → Reflect
- Laws of exponents: rules of 1, product, power, power of a product, power of a quotient, quotient, zero exponent, negative exponent
- Parentheses/sign warning and non-distribution over addition
- Interactive Math Lab
- Randomized Exponent Sprint
- Quick Check
- 10-item Final Boss
- XP and browser-local progress
- Print-friendly lesson summary
- Responsive mobile design
- EDJAY / Teacher Ed Learning Hub branding

## Branding
The supplied Teacher Ed logo asset is used as:
- `assets/BrandLogo.png` in the header and footer
- `assets/favicon.png` for the browser tab

## Run
Open `index.html` in a browser, or upload the folder to GitHub Pages / your existing Teacher Ed Learning Hub hosting.

No backend or build process is required.
