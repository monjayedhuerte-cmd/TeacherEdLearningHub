🧠 The Exponent Rulebook

These are the rules represented in your textbook pages 139–147.

01

Rules of 1

Any nonzero number raised to 1 stays itself. One raised to any exponent is 1.

x¹ = x   •   1ⁿ = 1
02

Product Rule

Same base multiplied? Keep the base and add the exponents.

xᵐ · xⁿ = xᵐ⁺ⁿ

Example: 2³ · 2⁵ = 2⁸.

03

Power Rule

A power raised to a power? Keep the base and multiply the exponents.

(xᵐ)ⁿ = xᵐⁿ

Example: (5²)³ = 5⁶.

04

Power of a Product

Distribute a power across factors multiplied together.

(xy)ⁿ = xⁿyⁿ

Example: (2·3)³ = 2³·3³.

05

Power of a Quotient

Raise both numerator and denominator to the same power.

(x/y)ⁿ = xⁿ/yⁿ

where y ≠ 0.

06

Quotient Rule

Same base divided? Subtract the exponents.

xᵐ/xⁿ = xᵐ⁻ⁿ

For m < n, rewrite as a reciprocal.

07

Zero Exponent

Any nonzero base raised to zero equals 1.

x⁰ = 1, x ≠ 0

Example: (5·2²·3⁴)⁰ = 1.

08

Negative Exponent

A negative exponent means the reciprocal with the positive exponent.

x⁻ⁿ = 1/xⁿ

Example: 3⁻⁴ = 1/3⁴.

09

Power ≠ Sum Distribution

A power does not distribute over addition or subtraction.

(x+y)ⁿ ≠ xⁿ+yⁿ

Example: (4+5)² = 81, but 4²+5² = 41.

⚠️ Parentheses matter: −4² = −16, but (−4)² = 16. The exponent applies only to the 4 unless parentheses include the negative sign.

🤝 Coach's Corner

Use the Singapore Math habit: identify the structure before calculating.

Step 1 — Name the structure

For 2³ · 2⁵, both powers have the same base.

Same base → Product Rule

Step 2 — Apply the operation

Add the exponents, not the bases.

2³⁺⁵ = 2⁸

Step 3 — Check reasonableness

2⁸ should be greater than 2⁵ because we multiplied by 2³.

2⁸ = 256
