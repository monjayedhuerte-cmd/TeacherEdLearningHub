GRADE 7 REAL NUMBER SUBSETS – ILAW INTERACTIVE WEBSITE
============================================================

Lesson:
Number and Algebra – Illustrate the different subsets of real numbers.

Duration:
2 days

ILAW:
I – Introduce: Number Detective Mission
L – Learn: Real Number Family Tree and classification
A – Apply: Quiz and Number Family Builder
W – Wrap-Up: Mastery Check and Reflection

Files:
- index.html
- style.css
- script.js
- BrandLogo.png

Branding:
- BrandLogo.png is used in the header and footer.
- BrandLogo.png is also the browser-tab favicon through:
  <link rel="icon" type="image/png" href="BrandLogo.png">

Features:
- Fully clickable navigation and ILAW stage cards
- Interactive number classification
- Day 1 sorting challenge
- Day 2 rational/irrational lab
- 8-item application quiz
- Number Family Builder
- 6-item mastery check
- Student reflection
- Full Screen button with browser API support and fallback
- Responsive mobile layout

IMPORTANT:
Keep all four files in the same folder. Open index.html in a modern browser.
