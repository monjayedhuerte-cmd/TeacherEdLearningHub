TEACHER ED LEARNING HUB
Grade 7 Mathematics — Data and Probability
Topic: Investigate Different Data Collection and Sampling Techniques
Duration: 3 Days
Strategy: ILAW (Introduce, Learn, Apply, Wrap-Up)

FILES
- index.html
- style.css
- script.js
- BrandLogo.png

HOW TO USE
1. Keep all four files in the same folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. The Teacher Ed logo is used in the header, footer, and browser tab.
4. The Full Screen button uses the browser Fullscreen API. If a browser blocks it, press F11.
5. Student reflections are saved locally in the browser using localStorage.

COMPETENCY
Investigate different data collection and sampling techniques.

The lesson is organized for three days and includes interactive quizzes, population/sample cards,
a sampling simulator, a sampling-plan builder, reflections, and a final mastery check.
