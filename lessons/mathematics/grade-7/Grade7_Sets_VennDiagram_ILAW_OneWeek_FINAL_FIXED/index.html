CONCEPT 01

Set & Elements

A set is a well-defined collection. The objects inside it are called elements or members.

A = {2, 4, 6, 8}

Here, 2, 4, 6, and 8 are elements of A. We can write 4 ∈ A, meaning “4 belongs to A.”
