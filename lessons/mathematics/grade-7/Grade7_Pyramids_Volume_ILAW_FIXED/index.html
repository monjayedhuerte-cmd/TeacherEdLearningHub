🧠 Know the Parts Before the Formula

The formula becomes easier when every symbol has meaning.

▱

Base

The polygon at the bottom. For this lesson, it is a rectangle or square.

B = base area
↕

Perpendicular Height

The shortest distance from the base to the apex, measured at a right angle to the base.

h = height
▲

Apex

The point where the triangular side faces meet.

Not the slant height
KEY IDEA

L • INDUCTIVE DERIVATION

📐 Discover the Pyramid Formula

Move from a familiar prism to a new rule.

1

Start with a rectangular prism

Suppose the prism has base area B and perpendicular height h.

Vprism = Bh
2

Compare equal base and height

A pyramid with the same base area B and same height h occupies one-third of the prism's volume.

≈
3

Generalize the pattern

One-third of the prism volume gives the pyramid volume:

Vpyramid = ⅓Bh

This is the volume formula for a square or rectangular pyramid.

Rectangular prismV = Bh
÷ 3
Square/rectangular pyramidV = ⅓Bh

🔑 Put in the Base Area

RECTANGULAR PYRAMIDB = lwV = ⅓lwhl = length, w = width, h = perpendicular height
SQUARE PYRAMIDB = s²V = ⅓s²hs = side length, h = perpendicular height
WORKED EXAMPLE

Rectangular Pyramid

Length = 6 cm, Width = 4 cm, Height = 9 cm

B = lw = 6(4) = 24 cm²
V = ⅓Bh = ⅓(24)(9)
V = 72 cm³
