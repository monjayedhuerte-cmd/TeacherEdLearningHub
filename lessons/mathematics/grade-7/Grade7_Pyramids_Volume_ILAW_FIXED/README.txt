FORMULA DERIVATION:
1. A rectangular prism with base area B and height h has V = Bh.
2. A square/rectangular pyramid with the same base area and perpendicular height has one-third the corresponding prism volume.
3. Therefore V_pyramid = 1/3 Bh.
4. Rectangular pyramid: B = lw, so V = 1/3 lwh.
5. Square pyramid: B = s², so V = 1/3 s²h.

IMPORTANT:
Use perpendicular height, not slant height, in the volume formula.
