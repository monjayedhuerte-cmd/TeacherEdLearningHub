1. What is a unit?

A unit is a standard amount used to describe a measurement. Examples include meter (m), centimeter (cm), kilogram (kg), liter (L), and second (s).

Measurement = Number + UnitExample: 4.5 km

🧭 The Direction Rule

Going to a smaller unit means more units are needed, so the number gets larger. Going to a larger unit means fewer units are needed, so the number gets smaller.

2 m → 200 cm ×100
2,000 g → 2 kg ÷1,000

🌎 Across Systems

Some problems use customary units. Use the conversion factor provided and keep units visible in your solution.

👨‍🏫 Teacher's Worked Example

Convert 4.5 km to m.

  1. Start with the given: 4.5 km.
  2. Know the relationship: 1 km = 1,000 m.
  3. Because km → m, multiply by 1,000.
  4. 4.5 × 1,000 = 4,500 m.
