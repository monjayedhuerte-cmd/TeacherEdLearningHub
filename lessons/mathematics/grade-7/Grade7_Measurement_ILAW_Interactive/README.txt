LESSON BASIS
Second Term, Weeks 1–2
Learning Area: Mathematics
Grade Level: 7
Learning Competency:
Convert units of measure within the International System of Units (SI)
and across different systems of measure.

ILAW FLOW USED IN THIS WEBSITE
I — INTRODUCE: motivation, context and prior thinking
L — LEARN: explicit concept building and interactive conversion tools
A — APPLY: guided practice and real-life problem solving
W — WRAP-UP: reflection, mastery check and feedback

FEATURES
- Responsive mobile/desktop design
- Teacher Ed Learning Hub branding in header and footer
- Curriculum connection section
- Interactive ILAW navigation
- Metric ladder
- Length, mass, capacity and temperature conversion machine
- Multiple-choice practice with instant feedback
- Real-life word problem
- Timed Unit Boss challenge
- Reflection activity
- Stars and progress tracking
- Mastery badge
- Quick challenge modal

HOW TO RUN
1. Put index.html, style.css, script.js and BrandLogo.png in one folder.
2. Double-click index.html or open it in VS Code with Live Server.
3. No server or database is required.

NOTE
The lesson uses an ILAW-style sequence (Introduce, Learn, Apply, Wrap-up) to structure the interactive learning experience. It is designed to support learner-centered, interactive instruction and the competency supplied by the teacher.
