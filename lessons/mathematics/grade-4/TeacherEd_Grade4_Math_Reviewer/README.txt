Topics based on the supplied textbook photos:
1. Decimal place value and aligning decimal points
2. Adding decimals, including annexing zeros and regrouping
3. Subtracting decimals, including regrouping across zeros
4. Applications involving measurements, money, and word problems

How to run
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Keep the assets folder beside index.html.
4. For GitHub Pages, upload the complete folder contents preserving this structure.

Progress is stored in localStorage on the same browser/device. This is a static offline-first site; no backend or student account is required.

Important content note:
The uploaded pages cover Grade 4-level decimal addition and subtraction. The reviewer uses the visible examples and exercises where legible and adds closely aligned practice questions for additional review. Always verify any textbook transcription against the original book before grading.
