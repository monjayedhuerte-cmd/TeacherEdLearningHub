TEACHER ED LEARNING HUB
Grade 4 Mathematics — Operation Quest
Topic: Series of Operations on Whole Numbers and Decimals

FILES
- index.html: website structure
- style.css: responsive design
- data.js: lesson-derived question bank and feedback
- script.js: interaction, progress, scoring, hints, confidence checks, results
- assets/teacher-ed-logo.png: supplied logo used in header/footer
- assets/favicon.png: supplied logo resized for browser tab

RUN
1. Extract the ZIP while preserving folders.
2. Open index.html in a modern browser.
3. Internet is not required for core functionality. Google Fonts are optional and fall back to system fonts.
4. Upload the complete folder to GitHub Pages or another static host to publish.

CONTENT SCOPE
Built from the supplied textbook pages for Lesson 3, “Series of Operations on Whole Numbers and Decimals.” Includes left-to-right addition/subtraction without grouping symbols, grouping symbols first, decimal operations, and word problems. It does not introduce multiplication/division precedence as a lesson rule because that was not taught in the supplied pages.

PROGRESS & PRIVACY
Progress is stored in localStorage on the same browser/device. No student name is requested and no data is sent to a server. Use Restart reviewer to clear local progress.

TEACHER NOTE
Please preview all items before classroom use. The reviewer is a practice aid and should not replace teacher instruction or the textbook.
