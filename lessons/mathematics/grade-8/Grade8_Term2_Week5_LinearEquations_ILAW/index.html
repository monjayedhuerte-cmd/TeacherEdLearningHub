⚖️ What Is an Equation?

An equation is a mathematical statement saying that two expressions have the same value. The symbol = means “is equal to.”

Expression3x + 5No equal sign is required.
Equation3x + 5 = 20Two sides are equal.
Think of the equal sign as a balance point. Whatever you do to one side must also be done to the other side.
15–23 min • L — LEARN

🔑 Vocabulary You Need

VariableA letter representing an unknown value.x
ConstantA number without a variable.7
CoefficientThe number multiplying a variable.4 in 4x
SolutionA value that makes the equation true.x = 3

Quick check: In 6x + 4 = 22, what is the coefficient of x?

23–31 min • L — LEARN

⚖️ The Properties of Equality

The equation stays true when we perform the same operation on both sides.

AddIf a = b, then a + c = b + c.
SubtractIf a = b, then a − c = b − c.
MultiplyIf a = b, then ac = bc.
DivideIf a = b, then a/c = b/c, c ≠ 0.
x + 4 =12Subtract 4 from BOTH sidesx=8

+ ↔ −
× ↔ ÷

7–16 min • L — LEARN

🧱 Simplify Before Solving

Some equations have like terms or variables on both sides.

3x + 4 + 2x = 29 Combine like terms → 5x + 4 = 29 Subtract 4 → 5x = 25 Divide 5 → x = 5

Like terms have the same variable part. For example, 3x and 2x are like terms.

16–24 min • L — LEARN

↔ Variables on Both Sides

Example: 5x + 2 = 2x + 17

Subtract 2x → 3x + 2 = 17
Subtract 2 → 3x = 15
Divide 3 → x = 5
🎯 Goal: collect variable terms on one side and constants on the other.
24–32 min • L — LEARN

✅ Always Check Your Answer

Substitute your answer into the original equation.

Equation: 4x + 3 = 27
Solution: x = 6
Check: 4(6) + 3 = 24 + 3 = 27 ✓
