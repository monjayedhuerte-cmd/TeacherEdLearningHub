How to use:
1. Keep all four files in the same folder.
2. Open index.html in Chrome, Edge, Firefox, Safari, or another modern browser.
3. Use the upper navigation to move between Overview, Day 1–5, and the 20-item assessment.
4. Each day is organized as a presentation-style slide deck for approximately 50 minutes.
5. Full Screen uses the browser Fullscreen API. If a browser blocks it, use the browser's own full-screen command.
6. The assessment is automatically scored in the browser. No student data is uploaded.

Source alignment:
The lesson follows the uploaded Grade 8 Mathematics Budget of Work. For Second Term Week 5, the BOW lists:
- Solve linear equations in one variable.
- Solve problems (e.g., number problems, geometry problems, and money problems) involving linear equations in one variable.

The BOW's Second Term performance standard includes solving linear equations and linear inequalities in one variable.
