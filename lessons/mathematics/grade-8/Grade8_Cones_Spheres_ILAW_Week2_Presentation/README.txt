FEATURES
- One-week classroom presentation (5 days)
- Each day is organized as an interactive slide deck
- ILAW: Introduce, Learn, Apply, Wrap-Up
- 50-minute class pacing built into the sequence
- Inductive derivation of cone and sphere volume formulas
- Interactive questions with immediate feedback
- Formula Lab with adjustable dimensions
- 20-item assessment with automatic scoring
- Full Screen button
- Responsive/mobile-friendly layout
- Teacher Ed branding in header and footer
- BrandLogo.png used as browser-tab favicon

HOW TO USE
1. Keep all files in the same folder.
2. Open index.html in Chrome, Edge, or another modern browser.
3. Use the day buttons to select the class day.
4. Use Previous/Next like a presentation.
5. Click Full Screen for classroom projection.
6. Open Formula Lab for additional exploration.
7. Use the 20-item assessment at the end.

LOGO
Keep BrandLogo.png beside index.html so both the header/footer logo and browser-tab favicon work.
