# Grade 2 Mental Addition Mission

A responsive interactive learning website based on the supplied primary-learning master prompt and textbook photos.

## Learning content
- Mental addition using number bonds and compatible numbers
- Commutative, associative, and identity properties of addition
- Sea-turtle egg word problem from the supplied lesson pages
- Singapore Math-inspired Concrete/Pictorial/Abstract progression, part-part-whole number bonds, and explicit modeling

## Features
- Connect → Teach → Model → Guided Practice → Independent Practice → Games → Application → Mastery Check
- Instant feedback and hints
- Three learning games
- Mastery scoring and practice-my-mistakes feedback
- Stars, badge, progress persistence through localStorage
- Fullscreen button, responsive layout, logo in header/footer, favicon
- Optional read-aloud feedback toggle
- No external libraries or database required

## Run
Open `index.html` in a modern browser, or use VS Code Live Server. The website uses only HTML, CSS, vanilla JavaScript, and local assets.
