## Properties of Addition

Standalone interactive lesson built from the supplied lesson reference and Teacher Ed Learning Hub master prompt.

2. Connect
3. Explore
4. Learn
5. Guided Practice
6. Topic-Specific Game
7. Practice
8. Think
9. Review
10. Check
11. Master
12. Reflect
13. Celebrate

### Core concepts
- Commutative Property: changing the order of addends does not change the sum.
- Associative Property: changing the grouping of addends does not change the sum.
- Identity Property: adding zero leaves the number unchanged.
- Strategy connection: use the properties to rearrange/regroup addends and make friendly tens.
