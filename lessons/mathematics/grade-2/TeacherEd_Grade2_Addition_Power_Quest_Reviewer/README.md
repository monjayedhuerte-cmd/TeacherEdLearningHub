# Teacher Ed Learning Hub — Grade 2 Math Addition Power Quest

## Contents
- Adding Without Regrouping
- Adding With Regrouping
- Commutative Property
- Associative Property
- Identity Property

## Features
- Engage, Connect, Explore, Learn, Guided Practice, Practice, Think, Review, Check, Master, Reflect, Celebrate
- Topic-specific interactive games
- Immediate explanatory feedback
- Hints
- Progress + XP
- LocalStorage progress
- Teacher Mode attention signals
- High-contrast and reduced-motion options
- Responsive/touch-friendly design
- Final mastery classification
- Missed-item review support
- User-provided Teacher Ed Learning Hub logo used as the branding asset

## Run
Because the lesson content is JSON-driven, open the folder using VS Code Live Server (or another local HTTP server), then open `index.html`.

Do not open the HTML directly with file:// if your browser blocks local JSON loading.
