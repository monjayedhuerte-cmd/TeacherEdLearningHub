# Problem Solving with Addition — Teacher Ed Learning Hub

A responsive, interactive Grade 2 mathematics lesson based on the uploaded textbook pages and the supplied Primary Interactive Learning master prompt.

## Run it
- Open `index.html` directly in a modern browser, or use VS Code Live Server.
- No installation, framework, server, or database is required.
- The Teacher Ed logo is used in the header, footer, and browser tab favicon.

## Included
- Ten-stage teaching journey: Connect, Learn the Steps, Watch Me, Let's Do It, Your Turn, Game Zone, Spiral Review, Brain Challenge, Mastery Check, Celebrate.
- Explicit five-step word-problem routine: identify what is asked, identify given data, choose operation, write number sentence, solve and label.
- Interactive choices with corrective feedback and hints.
- Worked examples based on the supplied lesson themes: fishing boats, turtle eggs, expenses, and books.
- Score, stars, stage completion, and progress saved in browser local storage.
- Fullscreen control, optional spoken welcome, keyboard-accessible buttons, mobile-friendly layout, and reduced-motion support.
- Reset progress control.

## Notes
The site uses HTML, CSS, and vanilla JavaScript. Student progress is stored locally in the browser only; no student data is sent to a server.
