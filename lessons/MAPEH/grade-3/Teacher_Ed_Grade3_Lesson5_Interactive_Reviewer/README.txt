# Teacher Ed Learning Hub — Grade 3 Lesson 5 Interactive Reviewer

## Source-based lessons
1. Physical Education — Lesson 5: Move Forward, Backward, and Sideward
2. Health — Lesson 5: Ways to be Healthy

The content is based on the supplied textbook photographs and the supplied Master Prompt.

## Run
Open `index.html` in a modern browser. No framework, server, or installation is required.

## Files
- index.html
- style.css
- script.js
- assets/TeacherEdLearningHubLogo.jpg

## Features
- Professional elementary-teacher instructional flow
- Connect → Teach → Model → Guided Practice → Independent Practice → Game Practice → Spiral Review → Application → Mastery
- Interactive answer checking and corrective feedback
- Hints
- Direction and health games
- Randomized choices in games and final checks
- Stars, badges, progress, mastery feedback
- Missed-question practice
- localStorage progress
- Reset progress
- Mobile/touch responsive layout
- Teacher Ed Learning Hub logo in header, footer, and favicon
