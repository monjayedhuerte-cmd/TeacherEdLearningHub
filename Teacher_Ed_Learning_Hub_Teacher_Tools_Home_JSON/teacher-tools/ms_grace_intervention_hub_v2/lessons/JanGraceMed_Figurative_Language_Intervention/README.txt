JanGraceMed Figurative Language Intervention Games
==================================================

GRADE 6 ENGLISH

FILES
-----
index.html
style.css
script.js
lessons.json
JanGraceMed.png

HOW TO USE
----------
1. Keep all files in the SAME folder.
2. Open index.html in a web browser.
3. The JanGraceMed logo is used in:
   - Header
   - Footer
   - Browser tab/favicon
4. No nested folders are required.
5. No server or Python is required.

GAME LEVELS
-----------
Easy       - Figurative Explorer
Average    - Meaning Matcher
Difficult  - Context Quest
Master     - Figurative Challenge

------
Simile

Idiom

FEATURES
--------
- Animated game interactions
- Immediate feedback
- Hints
- Score
- Streak
- Progress tracking
- LocalStorage saving
- Quick practice
- Responsive design
- JanGraceMed branding
- JSON lesson library

ADDING FUTURE LESSONS
---------------------
The JSON file is designed as the lesson library. For this standalone lesson,
the URL points to index.html. For a larger hub, additional HTML lesson files
can be placed in the same folder and referenced from lessons.json.

IMPORTANT
---------
Do not rename JanGraceMed.png unless you also update the image references.
