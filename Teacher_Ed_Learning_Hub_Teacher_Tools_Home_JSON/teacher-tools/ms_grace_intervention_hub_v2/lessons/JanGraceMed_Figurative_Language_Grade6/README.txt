JanGraceMed Types of Figurative Language — Grade 6 Intervention
Self-contained HTML/CSS/JS game lesson with Easy, Average, Difficult, and Master levels.
Branding logo is used in the header, footer, and browser tab.
The lesson is linked from lessons.json using:
"lessonType": "html", "url": "lessons/figurative-language-grade6/index.html"
Progress is saved locally in the browser.


FLAT FOLDER VERSION
===================
All website files are placed directly inside the same outside folder.
There is NO nested lessons/ folder.

Files:
- index.html
- lessons.json
- JanGraceMed.png
- figurative-language-grade6.html
- figurative-language-grade6.css
- figurative-language-grade6.js
- README.txt

Open index.html to start the website.
