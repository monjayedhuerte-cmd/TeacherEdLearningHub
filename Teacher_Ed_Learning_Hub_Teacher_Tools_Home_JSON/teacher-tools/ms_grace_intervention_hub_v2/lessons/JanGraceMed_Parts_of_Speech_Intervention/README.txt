ONE OUTSIDE FOLDER ONLY
-----------------------
All website files are directly inside this folder. There are no nested
lesson folders. This keeps the destination path short and helps avoid
Windows "Destination Path Too Long" errors.

Features
--------
- Animated educational game design
- Easy / Average / Difficult / Master progression
- 10 questions per level
- Randomized answer choices
- Immediate feedback and explanations
- Hints
- Score and streak system
- Animated confetti rewards
- LocalStorage progress
- Quick practice activity
- Responsive mobile/tablet/desktop layout
- No server, Python, database, or build process required
- JSON lesson entry included for the JanGraceMed lesson library

How to use
----------
1. Extract the ZIP.
2. Open index.html in Chrome or Microsoft Edge.
3. Keep all six files in the same folder.
4. Keep JanGraceMed.png beside index.html.

----------
The JavaScript was syntax-checked with Node.js before packaging.
