JanGraceMed Figures of Speech Intervention — FINAL
=====================================================

This is a self-contained Grade 6 English intervention game website.

ONE FOLDER ONLY
---------------
All files are directly inside the same folder. There are NO nested
lesson folders. This structure is intentionally short to reduce Windows
"Destination Path Too Long" problems.

Files:
- index.html
- style.css
- script.js
- lessons.json
- JanGraceMed.png
- README.txt

Branding
--------
The JanGraceMed logo is used in:
- Header
- Footer
- Browser tab/favicon

Games
-----
1. EASY — Figurative Scout
2. AVERAGE — Meaning Matcher
3. DIFFICULT — Context Quest
4. MASTER — Figure of Speech Master

Topics
------
- Simile
- Metaphor
- Personification
- Hyperbole
- Idiom

Features
--------
- Animated educational/game design
- Progressive difficulty
- 10 questions per level
- Immediate feedback and explanations
- Hints
- Score and streak system
- Confetti reward animation
- Progress saved with localStorage
- Quick practice activity
- Responsive desktop/tablet/mobile layout
- No Python, server, or database required

How to run
----------
Extract the ZIP.
Open index.html in Chrome, Edge, or another modern browser.

Important
---------
Keep JanGraceMed.png in the same folder as index.html.
Do not move the files into deeper folders unless you also update the
relative paths.
