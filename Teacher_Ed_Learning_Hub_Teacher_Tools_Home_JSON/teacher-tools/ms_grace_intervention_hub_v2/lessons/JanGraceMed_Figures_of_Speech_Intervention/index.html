📖 MINI LESSON

Know the Five Core Figures

Use the clues below before entering a game.
01

Simile

Compares two unlike things using like or as.

“He is as brave as a lion.”
02

Metaphor

Makes a direct comparison without using like or as.

“The classroom was a zoo.”
03

Personification

Gives human actions or qualities to nonhuman things.

“The wind whispered.”
04

Hyperbole

Uses deliberate exaggeration for emphasis or effect.

“I waited forever.”
05

Idiom

Uses a phrase whose intended meaning is different from its literal words.

“Break a leg!”
