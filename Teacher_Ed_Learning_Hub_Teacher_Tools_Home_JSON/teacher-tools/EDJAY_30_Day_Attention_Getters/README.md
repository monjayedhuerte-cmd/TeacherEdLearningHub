# EDJAY 30-Day Attention Getter Rotation

A standalone Teacher Ed Learning Hub teacher tool for Grades 1–3.

## Included
- 30-day rotation of classroom attention getters
- Grade 1, Grade 2, and Grade 3 coverage
- Math, English, Science, Filipino, Araling Panlipunan, Transition, Group Work, and Noisy Class Reset categories
- Search and filtering
- Random Getter
- Day-by-day navigation
- Teacher cue + student response
- Teacher Move + Best For guidance
- Read Cue using browser speech synthesis
- Copy Cue
- Favorite routines saved in localStorage
- Fullscreen Presentation Mode
- Print-friendly layout
- Responsive desktop/tablet/mobile design
- EDJAY / Teacher Ed Learning Hub logo in header, footer, presentation mode, and webtab favicon
- No external libraries or dependencies

## Use
Open `index.html` in a modern browser. It can be hosted directly on GitHub Pages or another static host.

## Important classroom-management principle
Use the attention signal once, wait for the expected student response, and reinforce the routine. Do not train students to ignore the signal by repeating it continuously.
