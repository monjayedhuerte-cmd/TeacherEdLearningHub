CLASSROOM EXIT TICKET — TEACHER ED

Open index.html in Chrome, Edge, or Firefox.

FEATURES
- 10 ready-made exit-ticket prompts
- Random question picker
- Custom question
- Student name (optional)
- Student answer box
- 1, 2, or 3 minute response timer
- Fullscreen/projector mode
- Local response storage using browser localStorage
- Teacher response board
- CSV export
- No server, database, or internet required after loading

PRIVACY
Responses are stored only in the browser/device running this page. They are not uploaded to a server. Clearing browser site data may remove saved responses.

WORKFLOW
1. Choose or randomly generate a question.
2. Project the question.
3. Set the response time.
4. Students submit their answers.
5. Review the Response Board or export the responses as CSV.

The tool is designed as a lightweight classroom aid. For sensitive student records, use your school's approved storage system.
