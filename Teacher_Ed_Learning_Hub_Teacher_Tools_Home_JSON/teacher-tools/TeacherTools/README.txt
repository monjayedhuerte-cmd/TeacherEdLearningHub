PUT THE HOMEPAGE IN THE SAME PARENT FOLDER AS YOUR TOOL FOLDERS:
Teacher-Tools/
  index.html
  style.css
  script.js
  student-participation/index.html
  classroom-timer/index.html
  attention-getter/index.html
  noise-meter/index.html
  exit-ticket/index.html
  brain-break/index.html
  quick-class-poll/index.html

The paths are defined in script.js in the tools array. If your folders have different names, change the final URL for that tool.

The homepage is pure HTML/CSS/JS, responsive, searchable, categorized, and GitHub Pages compatible. You can add future tools by copying a tool entry in script.js.
