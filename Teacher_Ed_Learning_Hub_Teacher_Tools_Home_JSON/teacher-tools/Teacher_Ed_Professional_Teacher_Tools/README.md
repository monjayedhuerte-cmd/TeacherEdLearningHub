# Teacher Ed Professional Teacher Tools

A polished, offline-friendly vanilla HTML/CSS/JavaScript teacher toolkit branded for Teacher Ed Learning Hub.

## Features
- 54 teacher tools organized by classroom purpose
- Teacher Ed / EDJAY branding in favicon, header, dashboard and footer
- Reusable question bank with localStorage persistence
- Question customization for every question-based game
- Import/export JSON question sets
- Game setup with subject, grade, timing, scoring and randomization
- Presentation-friendly game screens
- Sound toggle and reduced-motion mode
- Responsive desktop/tablet/mobile layout
- No backend required for core use

## Run
Open the folder through a simple local web server because the app loads JSON files with `fetch()`.

Examples:
- VS Code Live Server
- `python -m http.server`
- GitHub Pages / Cloudflare Pages

## Branding
The supplied Teacher Ed logo is used without redesigning it. To change the asset path, update the image references in `index.html` and `script.js`.
