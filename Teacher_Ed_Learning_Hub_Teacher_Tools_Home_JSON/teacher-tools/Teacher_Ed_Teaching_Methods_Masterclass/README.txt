TEACHER ED — TEACHING METHODS MASTERCLASS
==========================================

CONTENTS
- index.html  Main website structure
- style.css   Responsive navy-and-gold design
- script.js   25 method lessons, filters, progress, quiz, teaching planner

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Click any method card to open its lesson.
4. Mark lessons complete to track your progress.
5. Search/filter the methods and use the scenario practice.
6. Save a classroom plan using the planner. Progress and plans are stored in
   your browser's localStorage on that device.

HOSTING
This is a static HTML/CSS/JavaScript project. Upload the three files to a
GitHub Pages repository or place them in a folder on your website.

BRANDING
The site uses editable text branding for "Teacher Ed" / "EDJAY" in navy and
gold. If you want to use your existing official logo, place the image in this
folder and update the brand markup in index.html to use that image without
stretching or altering the logo.

NOTES
- No framework or build step is required.
- Google Fonts are loaded online; system fallback fonts are provided.
- Learning progress and saved plans stay in the current browser unless its
  site data is cleared. They are not synced across devices.
