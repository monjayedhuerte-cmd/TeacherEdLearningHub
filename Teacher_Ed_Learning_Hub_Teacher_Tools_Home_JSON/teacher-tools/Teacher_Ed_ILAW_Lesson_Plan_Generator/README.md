# Teacher Ed Learning Hub — ILAW Lesson Plan Generator

A client-side HTML/CSS/JavaScript teacher tool for creating an editable ILAW-aligned lesson plan.

## Files
- `index.html` — interface and document structure
- `style.css` — responsive styling and print layout
- `script.js` — form logic, generation, local saving, checker, and Word-compatible export
- `BrandLogo.png` — Teacher Ed Learning Hub logo supplied by the user

## Use
Open `index.html` in a modern browser. No server is required.

## GitHub Pages
1. Upload all files to a repository.
2. Ensure `index.html` is in the published folder.
3. Enable GitHub Pages from the repository settings.
4. Open the generated Pages URL.

## Notes
- Drafts are stored in the browser's LocalStorage.
- The Word export is a Word-compatible `.doc` file generated entirely in the browser.
- Print / PDF uses the browser print dialog.
- Official competencies, standards, and codes must be verified by the teacher.
- The generated plan is a planning aid and is not represented as an official DepEd template.
