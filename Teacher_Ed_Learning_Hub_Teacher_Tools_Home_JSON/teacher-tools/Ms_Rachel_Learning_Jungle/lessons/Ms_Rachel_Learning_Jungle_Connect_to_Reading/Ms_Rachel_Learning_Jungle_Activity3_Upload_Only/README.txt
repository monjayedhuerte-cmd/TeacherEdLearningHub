MS. RACHEL'S LEARNING JUNGLE
Interactive Lesson: Connect to Reading

This website is based on the supplied lesson plan for Teacher Rachel D. Medina.

SOURCE-BASED LEARNING TARGETS:
1. Children will listen to an informational text to understand the main idea.
2. Children will exchange ideas with others through collaborative discussions on academic topics.
3. Children will write words to complete sentences.
4. Children will closely read informational texts to determine how meaning is conveyed through language.

INCLUDED:
- WIDA Standard 4 section from the supplied plan
- Fiction vs. Nonfiction activity with 10 book examples
- Visualization practice using the three supplied sentences
- School Places Part 1 with 5 picture placeholders
- School Places Part 2 spelling practice
- Partner discussion prompts and sentence frames
- Dedicated Maria Is Lost reading area (the actual book is not recreated)
- Main idea listening/reading activity
- Sentence completion activity
- Big Idea: I LEARN AT SCHOOL. / I HAVE FUN AT SCHOOL.
- Ms. Rachel branding throughout
- Text-to-speech buttons
- Mobile responsive design

ADD YOUR SCHOOL PICTURES:
In index.html, replace each picture-slot div with:
<div class="picture-slot">
  <img src="images/library.jpg" alt="Library">
</div>

Then add this CSS:
.picture-slot img{
  width:100%;
  height:100%;
  object-fit:cover;
  border-radius:12px;
}

The five picture cards are intentionally separate so Ms. Rachel can choose which real school photos to use.
