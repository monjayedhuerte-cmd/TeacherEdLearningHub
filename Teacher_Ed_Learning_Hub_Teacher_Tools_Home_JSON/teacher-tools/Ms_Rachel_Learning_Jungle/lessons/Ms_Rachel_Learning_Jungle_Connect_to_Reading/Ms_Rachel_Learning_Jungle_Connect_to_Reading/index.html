Find the Main Idea

👂 Ms. Rachel says: The main idea tells what the text is mostly about. Listen and look for the idea that connects the details.

🏫 I Learn at School

School is a place for learning and fun. At school, children learn in many places. They can read books in the library, learn with classmates in the classroom, and play on the playground. Each place helps children learn and enjoy school.
