MS. RACHEL'S LEARNING JUNGLE
CONNECT TO MATHEMATICS — INTERACTIVE WEBSITE

This website is based on the supplied Connect to Mathematics lesson content.

INCLUDED:
- WIDA English Language Development Standard 3
- Four learning targets: Listening, Speaking, Writing, Reading
- Vocabulary: Numbers, Measure, Shapes, Time
- Real-life math examples: market, road signs, department stores, classroom, calendar, clock
- Counting activity
- Interactive number chart 1–20 with speech
- Measuring activity using inches/units
- Same/Different Shapes activity
- Stopwatch activity
- Classroom Number Hunt
- Partner communication questions
- Sentence frames
- Big Idea and completion mission

OPENING:
Open index.html in a browser. Live Server in VS Code is recommended.

The website uses browser text-to-speech when available.
No external image files are required.
