Teacher Ed Learning Hub — Teacher Tools

This version intentionally contains NO active teacher tools on the landing page. The only navigation tab is Home.

Logo: assets/teacher-ed-logo.png
The logo is used in the header, footer, hero, and browser favicon.

Upcoming tools are registered in teacher-tools.json. Future pages can be added using the file paths in that JSON registry.

To add this folder to your main website, place teacher-tools/ beside your main index.html.
Main navigation example:
<a href="teacher-tools/index.html">Teacher Tools</a>

The JSON registry is only a planning/registry file at this stage; no tool pages are included or activated.
