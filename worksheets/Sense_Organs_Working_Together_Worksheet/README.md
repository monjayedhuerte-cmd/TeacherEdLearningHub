# Science 1 Worksheet — Sense Organs Working Together

Interactive and printable Grade 1 Science worksheet based on the provided Lesson 8 reference pages and the supplied Worksheet Website Master Prompt.

## Files
- index.html — worksheet interface
- style.css — responsive and print styles
- script.js — interactions, scoring, local storage, teacher mode
- data/worksheet.json — editable worksheet content
- assets/logo.png — supplied Teacher Ed logo

## Use
Open `index.html` in a modern browser. For the JSON file to load reliably, use a simple local web server if your browser blocks fetch() from local files. GitHub Pages will work directly.

## Privacy
Student responses stay in the browser using localStorage. No external account or service is required.
